# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **TelegramPublisher**, please send an email to `security@vyntech.com.au`. Please do not report security vulnerabilities through public GitHub issues.

All security vulnerabilities will be promptly addressed.
